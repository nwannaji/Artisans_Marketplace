============================================================================================
1. Authentication
Firebase Auth (OTP/email-password)

Role-based login (Customer / Artisan / Admin)

2. Artisan Registration
Personal info, profession, bank info, upload docs

Location auto-filled via GPS

3. Customer Dashboard
Search bar + filters (location, price, profession)

Artisan list with distance, rating, cost

4. Job Booking + Scheduler
Select artisan → Pick date/time via showDatePicker()

Store job as "scheduled"

Set up local/FCM reminder 1 hour before appointment

5. Chat System (Firebase Firestore)
chats/{chatId}/messages/{message}

Uses Firestore or Socket.IO for real-time chat

Flutter plugin: flutter_chat_ui or flutter_socket_io

6. Google Maps Integration
Use google_maps_flutter & geolocator

Show artisan on map

Directions from customer location to artisan

7. In-App Wallet System
Customer wallet balance → Pay from wallet or card

Artisan wallet reflects job earnings

Transfer button (to bank via Paystack/Flutterwave)

Admin wallet → receives commission

8. Dispute Resolution (Admin Dashboard)
View flagged jobs (e.g., "Not completed", "Poor service")

Contact both parties via chat/email

Decide to refund or release payment
========================================================================
Admin Dashboard (Django Admin or Flutter Web)
Admin can:

Verify artisans

Suspend users

See all bookings & wallet activity

View unresolved disputes

Manage app settings (commission %, payout delay)
===========================================================================
Booking Flow Example
Customer searches → selects artisan

Books service for April 14 @ 10:00 AM

Reminder sent via Firebase Cloud Messaging (9:00 AM)

Job is marked as Completed

Customer rates artisan

Payment auto-transferred to artisan wallet

Artisan can withdraw to bank
